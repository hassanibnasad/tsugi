## 2. Intended Use & Architecture

### Intended Use
Tsugi is an enterprise-grade terminal Git assistant that autonomously diagnoses complex, stuck, or conflicting Git repository states (diverged branches, interrupted rebases, unmerged conflicts, detached HEADs) and generates verified, step-by-step resolution plans.

### Four-Layer Safety Pipeline
```
[User Git Issue]
       │
       ▼
1. Deterministic Probe (libgit2 <10ms) ──► Produces compact RepoState fact sheet (~150 tokens)
                                           with worktree, remote, submodule & graph topology
       │
       ▼
2. Tier-0 Fast-Path (<2ms) ──────────────► 80+ deterministic patterns (no LLM required)
       │ (if unhandled)
       ▼
3. Local SLM Inference (GBNF Grammar) ───► Strict JSON plan generation (Qwen2.5-Coder-1.5B)
                                           with rolling multi-turn conversation memory
       │
       ▼
4. Guardrail Policy & Safety Vault ──────► Validates commands, checks risk tier,
                                          creates 3-parent shadow snapshot commit,
                                          and executes through interactive observer.
```

## 3. GBNF Grammar Constrained Output

Every plan output generated by the model strictly conforms to the compiled GBNF grammar (`grammars/tsugi_plan.gbnf`), guaranteeing parseable JSON:

```json
{
  "root_cause": "Divergent branch history following remote rebase",
  "risk_tier": "MUTATING_SAFE",
  "execution_steps": [
    {
      "cmd": "git stash push -u -m 'pre-rebase snapshot'",
      "explanation": "Protect dirty working tree changes",
      "requires_confirmation": false
    },
    {
      "cmd": "git rebase origin/main",
      "explanation": "Replay local commits onto updated upstream",
      "requires_confirmation": false
    }
  ],
  "rollback_cmd": "git rebase --abort"
}
```

### Risk Tiers
- `READ_ONLY`: Informational queries, log inspections, status checks.
- `MUTATING_SAFE`: Non-destructive worktree adjustments (stash, switch, fetch).
- `MUTATING_DANGEROUS`: Changes altering index or working tree (clean, hard reset).
- `HISTORY_REWRITE`: Git history modification (rebase, amend, force push with lease).

## 5. Quick Start & Automated Installation

Developers do not need to manually download model weights or install Python:

```bash
# Automated zero-touch setup: downloads llama-cli & GGUF with SHA-256 verification
tsugi setup

# Check system readiness
tsugi status

# Install fail-safe Git guard hooks (<15ms automatic pre-operation snapshots)
tsugi guard install

# Diagnose and resolve any Git failure
tsugi fix "my rebase failed with conflicts"
```
